# Measuring the Measurers

Generalizability-theory analysis of LLM-as-a-Judge reliability on **WildBench v2.0522** and **Arena-Hard v0.1**. Secondary analysis only — no new model inference, no API calls.

> **Note on benchmark choice.** The pre-analysis plan named MT-Bench as the primary benchmark, but the only publicly released MT-Bench single-score judgment file is `gpt-4_single.jsonl`; `gpt-3.5-turbo_single.jsonl` and `claude-v1_single.jsonl` were never released. The project pivoted to **WildBench v2.0522** (2 LLM judges × 41 common models × 1024 items, 1–10 Likert) as the primary benchmark while keeping Arena-Hard as the secondary. See [`PIVOT.md`](PIVOT.md) for the full rationale and impact on pre-registered hypotheses.

## Quickstart

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
bash scripts/reproduce_all.sh
```

`scripts/reproduce_all.sh` regenerates every figure and table from raw downloads to final outputs in under 15 minutes on a CPU.

## Repo layout

```
src/
  ingest/        # download and unify per-benchmark judgment releases
  analysis/      # G-study (variance components) + D-study + RFP derivations
  viz/           # variance pie, RFP heatmap, replication table
  utils/         # RNG seeds, shared helpers
tests/           # smoke tests on ingest row counts and crossing
scripts/         # reproduce_all.sh end-to-end driver
data/
  raw/           # downloaded as-is; .gitignored
  processed/     # canonical long-form parquets
outputs/         # figures/ and tables/ regenerated by scripts
```

## Manuscript

The full results paper is at [`../manuscript.tex`](../manuscript.tex) at the project root (kept outside this code repo so the code-submission tarball doesn't carry the LaTeX source). It references the figures generated under `outputs/figures/`. To compile on Overleaf, upload the four files at the project root (`manuscript.tex`, `references.bib`, `neurips_2025.sty`, `pre_analysis_plan.tex`) plus the two figure PDFs:

```
code/outputs/figures/variance_decomposition.pdf
code/outputs/figures/rfp_heatmap.pdf
```

(Or run `bash scripts/reproduce_all.sh` first to regenerate them.)

1. $\sigma^2_{mj} \geq 0.1 \cdot \sigma^2_m$ on both benchmarks.
2. At $n_j=1,\,n_i=80$ (or each benchmark's modal-practice item count), adjacent-pair RFPs exceed 20% for at least one model pair on each benchmark.
3. The relative ordering of $\sigma^2_m, \sigma^2_j, \sigma^2_i, \sigma^2_{mj}$ is preserved between WildBench and Arena-Hard.
